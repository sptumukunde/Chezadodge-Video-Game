# ChezaDodge arena packs

3D worlds downloaded by the game the first time an arena is played
(see `scripts/packs.gd` in the game). Each `.pck` is a Godot resource pack
built by `tools/build_packs.gd` from the worlds made with `tools/arenas/*.py`
on the main branches (Poly Haven / ambientCG textures are CC0).

`v1/` matches `Packs.VERSION = 1` in the game.
